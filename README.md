# Odin Recipes

A simple HTML recipe website featuring Filipino dishes from different regions and cultures.

## Recipes

- [Sinuglaw](recipe/sinuglaw.html) - Cebuano grilled pork and tuna ceviche
- [Kinalas](recipe/kinalas.html) - Bicolano noodle soup
- [Piyanggang Chicken](recipe/piyanggang.html) - Tausug chicken with charred coconut sauce

## Usage

Open [index.html](index.html) in a web browser to view the recipe collection.
